# 🌦️ Weather App

Real-time weather lookup powered by a public API and vanilla JavaScript.

![JavaScript](https://img.shields.io/badge/JavaScript-F0DB4F?style=flat-square&logo=javascript&logoColor=black)
![API](https://img.shields.io/badge/API-fetch-4F8CFF?style=flat-square)
![Status](https://img.shields.io/badge/status-live-4ADE80?style=flat-square)

**🔗 Live:** [knowtheweater.netlify.app](https://knowtheweater.netlify.app/)

## Features
- Live weather data via a public weather API
- Async `fetch` + JSON parsing
- Clean, responsive results display

## Tech Stack
`HTML` `CSS` `JavaScript` `Fetch API`

## Run locally
```bash
git clone https://github.com/Ankit-4234/weather-app.git
cd weather-app
open index.html
```
